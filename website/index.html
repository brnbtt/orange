05 / Details

Before installing.

What hardware do I need?

A 64-bit Windows 10 or Windows 11 PC. Sharing requires a compatible hardware H.265 or H.264 encoder. Keep your graphics drivers current; hardware and Windows version affect feature support.

Do I need a Discord account?

You can host and join with a room code without signing in. Both players need Discord sign-in to exchange friend requests and use the synced friends list. Orange is independent of Discord.

Is a friend code the same as a room code?

No. A personal friend code identifies a player so you can send them a request. A room code joins an active stream. Use Add friend for the first and Join with a code for the second.

Who can join my stream?

Anyone who has your room code can join and can pass it on. The friends list controls who can discover your stream; it doesn't restrict access to people with the code.

What does the installer include?

The Windows app and its media runtime. It installs for your user and creates a Start menu shortcut. Download buttons on this site link directly to Orange's Azure release storage.
