A few good questions

Before you jump in.

What do we need to run Orange?

Both people need a 64-bit Windows 10 or Windows 11 PC and Orange installed. Sharing uses a compatible hardware H.265 or H.264 encoder. Keep your graphics drivers up to date; hardware and Windows version affect feature support.

Is Orange free?

Yes. Orange is free and open source under the MIT license. You can explore the code, report an issue, or contribute on GitHub.

Do I need a Discord account?

No. You can share and join with a room code without signing in. Discord sign-in adds your name and avatar, and lets friends see when you're streaming. Orange is an independent app, not affiliated with Discord.

Does the stream go through a server?

Your video and audio travel directly between PCs. A small relay helps you connect. Upload usage grows with each viewer, and networks that require a TURN relay aren't supported yet.

What should I know about the beta?

Orange is still being refined. The current installer is not yet code-signed, so Windows may show an unrecognized-app warning. Download only from the official release links. Found something odd? Tell us on GitHub.
